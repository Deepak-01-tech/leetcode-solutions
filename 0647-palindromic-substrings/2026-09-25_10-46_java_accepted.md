## Solution

```java
class Solution {
    public int countSubstrings(String s) {
        int len=0;
        for(int i=0;i<s.length();i++){
             len+=exp(s,i,i);
             len+=exp(s,i,i+1);
        }
        return len;
    }
    private int exp(String s,int left,int right){
        int len=0;
        while(left>=0 && right<s.length() && s.charAt(left)==s.charAt(right)){
            left--;right++;
            len++;
        }
        return len;
    }
}
```
