## Solution

```java
class Solution {
    public int compress(char[] chars) {
        int i=0;
        int r=0;
        int c;
        while(i<chars.length){
            c=0;
            char ch=chars[i];
            while(i<chars.length && ch==chars[i]){
                c++;
                i++;

            }
            chars[r++]=ch;
            if(c>1){
                String s=Integer.toString(c);
                for(char cho : s.toCharArray()){
                    chars[r++]=cho;
                }
            }
            
        }
        return r;
        
    }
}
```
