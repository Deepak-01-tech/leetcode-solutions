## Solution

```java
class Solution {
    public boolean isPalindrome(String s) {
        String a="";
        s=s.replaceAll("[^a-zA-Z0-9]","");
        for(int i=s.length()-1;i>=0;i--){
            a+=Character.toLowerCase(s.charAt(i));

        }
        if(!s.toLowerCase().equals(a)){
            return false;
        }
        return true;
    }
}
```
