## Solution

```java
class Solution {
    public String simplifyPath(String path) {
        Stack<String> sk=new Stack<>();
        for(String s : path.split("/")){
            if(s.equals("") || s.equals(".")){
                continue;
            }
            else if(s.equals("..")){
                if(!sk.isEmpty()){
                    sk.pop();

                }
            }
            else{
                sk.push(s);
            }
        }
        return "/"+ String.join("/",sk);
        
    }
}
```
