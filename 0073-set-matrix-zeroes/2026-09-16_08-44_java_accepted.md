## Solution

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int rows=matrix.length;
        int col=matrix[0].length;
        boolean[] row =new boolean[rows];
        boolean[] cols =new boolean[col];
        for(int i=0;i<rows;i++){
            for(int j=0;j<col;j++){
                if(matrix[i][j]==0){
                    row[i]=true;
                    cols[j]=true;
                }
            }
        }
        for(int i=0;i<rows;i++){
            for(int j=0;j<col;j++){
                if(row[i] || cols[j]){
                    matrix[i][j]=0;
                }
            }
        }
        
    }
}
```
