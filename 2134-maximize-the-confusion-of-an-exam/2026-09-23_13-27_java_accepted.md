## Solution

```java
class Solution {
    public int maxConsecutiveAnswers(String answerKey, int k) {
        int [] a =new int[26];
        int l=0;
        int max=0;
        int r=0;
        for(int i=0;i<answerKey.length();i++){
            char ch=answerKey.charAt(i);
            a[ch-'A']++;
            max =Math.max(max,a[ch-'A']);
            int w=i-l+1;
            int rep=w-max;
            if(rep>k){
                a[answerKey.charAt(l)-'A']--;
                l++;
            }
            r=Math.max(r,i-l+1);
        }
        return r;
        
    }
}
```
