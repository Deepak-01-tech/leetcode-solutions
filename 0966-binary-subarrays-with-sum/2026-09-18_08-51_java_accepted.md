## Solution

```java
class Solution {
    public int numSubarraysWithSum(int[] nums, int goal) {
        HashMap<Integer,Integer> map=new HashMap<>();
        map.put(0,1);
        int r=0;
        int sum=0;
        int c=0;
        while(r<nums.length){
            sum+=nums[r];
            if(map.containsKey(sum-goal)){
                c+=map.get(sum-goal);

            }
            map.put(sum,map.getOrDefault(sum,0)+1);
            r++;
        }
        return c;
    }
}
```
