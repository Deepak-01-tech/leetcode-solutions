## Solution

```java
class Solution {
    public boolean checkSubarraySum(int[] nums, int k) {
        HashMap<Integer,Integer> map=new HashMap<>();
        map.put(0,-1);
        int prefix=0;
        int rem=0;
        for(int i=0;i<nums.length;i++){
            prefix+=nums[i];
            rem= prefix % k;
            if(map.containsKey(rem)){
                if(i-map.get(rem)>=2){
                    return true;
                }
            }
            else{
                map.put(rem,i);
            }
        }
        return false;
        
    }
}
```
