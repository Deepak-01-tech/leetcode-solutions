## Solution

```java
class Solution {
    public int maxProduct(int[] nums) {
        int cs=nums[0];
        int max=nums[0];
        int min=nums[0];
        for(int i=1;i<nums.length;i++){
            int v=nums[i];
            if(v<0){
                int temp=max;
                max=min;
                min=temp;
            }
            max=Math.max(v,max*v);
            min=Math.min(v,min*v);
            cs=Math.max(cs,max);
        }
        return cs;
    }
}
```
