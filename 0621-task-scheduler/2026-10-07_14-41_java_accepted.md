## Solution

```java
class Solution {
    public int leastInterval(char[] tasks, int n){
        int[] arr=new int[26];
        for(char ch : tasks){
            arr[ch-'A']++;
        }
        int max=0;
        for(int i=0;i<26;i++){
            max=Math.max(max,arr[i]);
        }
        int c=0;
        for(int i=0;i<26;i++){
            if(arr[i]==max) c++;
        }
        return Math.max(tasks.length,((max-1)*(n+1)+c));
        
    }
}
```
