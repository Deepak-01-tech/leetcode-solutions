## Solution

```java
class Solution {
    public List<String> removeAnagrams(String[] words) {
        HashSet<String> set =new HashSet<>();
        ArrayList<String> list=new ArrayList<>();
        String prev="";
        for(String s : words){
            char[] c=s.toCharArray();
            Arrays.sort(c);
            String a= new String(c);
            if(!a.equals(prev)){
                list.add(s);
                prev =a;

            }
        }
        return list;
        
    }
}
```
