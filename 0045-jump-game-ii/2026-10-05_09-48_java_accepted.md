## Solution

```java
class Solution {
    public int jump(int[] nums) {
        int c=0;
        int st=0;
        int end=0;
        for(int i=0;i<nums.length-1;i++){
            end=Math.max(end,i+nums[i]);
            if(end>=nums.length-1){
                ++c;
                break;
            }
            if(i==st){
                ++c;
                st=end;

            }
            
        }
        return c;
        
    }
}
```
