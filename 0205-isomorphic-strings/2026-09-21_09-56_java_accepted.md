## Solution

```java
class Solution {
    public boolean isIsomorphic(String s, String t) {
        int[] arr=new int[256];
        int[] arr1=new int[256];
        for(int i=0;i<s.length();i++){
            int a=s.charAt(i);
            int b=t.charAt(i);
            if(arr[a]!=arr1[b]){
                return false;
            }
            arr[a]=i+1;
            arr1[b]=i+1;
        }
        return true;
        
    }
}
```
