## Solution

```java
class Solution {
    public String minRemoveToMakeValid(String s) {
        StringBuilder sb = new StringBuilder();
        int c = 0;

        for (char ch : s.toCharArray()) {
            if (ch == '(') {
                c++;
                sb.append(ch);
            }
            else if (ch == ')') {
                if (c > 0) {
                    c--;
                    sb.append(ch);
                }
            }
            else {
                sb.append(ch);
            }
        }

        StringBuilder ans = new StringBuilder();
        for (int i = sb.length() - 1; i >= 0; i--) {
            char ch = sb.charAt(i);

            if (ch == '(' && c > 0) {
                c--;
            }
            else {
                ans.append(ch);
            }
        }

        return ans.reverse().toString();
    }
}
```
