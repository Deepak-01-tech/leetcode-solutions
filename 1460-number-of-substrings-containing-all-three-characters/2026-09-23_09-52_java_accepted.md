## Solution

```java
class Solution {
    public int numberOfSubstrings(String s) {
         int[] ans=new int[3];
         int l=0;
         int count =0;
         for(int r=0;r<s.length();r++){
            ans[s.charAt(r)-'a']++;
            while(ans[0]>0 && ans[1]>0 && ans[2]>0){
                count+=s.length()-r;
                ans[s.charAt(l)-'a']--;
                l++;
            }
         }
         return count;
        
    }
}
```
