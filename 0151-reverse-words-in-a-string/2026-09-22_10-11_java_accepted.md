## Solution

```java
//import java.logicroggers.*;
class Solution {
    public String reverseWords(String s) {
        String a="";
        s=s.trim();
        String[] word=s.split("\s+");
        for(int i=word.length-1;i>=0;i--){
            a+=word[i];
            if(i!=0){
                a+=" "; 
            }
        }
        return a;
    }
}
```
