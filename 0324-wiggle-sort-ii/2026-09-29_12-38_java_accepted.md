## Solution

```java
import java.util.*;

class Solution {
    public void wiggleSort(int[] nums) {
        int[] a = nums.clone();
        Arrays.sort(a);

        int n = nums.length;
        int mid = (n + 1) / 2;

        int l = mid - 1;
        int r = n - 1;

        for (int i = 0; i < n; i++) {
            if (i % 2 == 0) {
                nums[i] = a[l--];
            } else {
                nums[i] = a[r--];
            }
        }
    }
}
```
