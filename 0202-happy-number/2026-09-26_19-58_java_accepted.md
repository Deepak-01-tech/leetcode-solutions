## Solution

```java
class Solution {
    public boolean isHappy(int n) {
        while(n!=1 && n!=4){
            int sum=0;
            while(n!=0){
                int pr=n%10;
                sum+=pr*pr;
                n/=10;

            }
            n=sum;
        }
        return n==1;


    }
}
```
