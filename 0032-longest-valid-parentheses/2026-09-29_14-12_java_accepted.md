## Solution

```java
class Solution {
    public int longestValidParentheses(String s) {
        Stack<Integer> sk=new Stack<>();
        sk.push(-1);
        int max=0;
        for(int i=0;i<s.length();i++){
            if(s.charAt(i)=='('){
                sk.push(i);
            }
            else{
                sk.pop();
                if(sk.isEmpty()){
                    sk.push(i);
                }
                else{
                    max=Math.max(max,i-sk.peek());
                }
            }
        }
        return max;
        
    }
}
```
