## Solution

```java
class Solution {
    public int equalSubstring(String s, String t, int maxCost) {
        int l=0;
        int maxl=0;
        int diff=0;
        for(int i=0;i<s.length();i++){
            diff+=Math.abs(s.charAt(i)-t.charAt(i));
            while(diff>maxCost){
                diff-=Math.abs(s.charAt(l)-t.charAt(l));
                l++;
            }
            maxl=Math.max(maxl,i-l+1);
        }
        return maxl;

        
    }
}
```
