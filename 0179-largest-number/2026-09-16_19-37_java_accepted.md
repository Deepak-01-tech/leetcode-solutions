## Solution

```java
class Solution {
    public String largestNumber(int[] nums) {
        String a="";
        String[] s=new String[nums.length];
        for(int i=0;i<nums.length;i++){
            s[i]=String.valueOf(nums[i]);
        }
        Arrays.sort(s,(x,y)->(y+x).compareTo(x+y));
        if(s[0].equals("0")){
            return "0";
        }
        for(int i=0;i<nums.length;i++){
            a+=s[i];
            
        }

        return a;
        
    }
}
```
